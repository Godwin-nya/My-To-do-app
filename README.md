This project is a hard-coded project to test my abilities in the web development landscape. It is an app that let the user add what he intends to do everyday.

For now, you can do the following in the app:

1. Add a task
2. Delete a task
3. Mark a task as done, and
4. Edit a task.



I intend to add more features in the future to make the app useful to everybody.

Thank you as you experiment. Feel free to contribute your suggestions to this project.
